# Worst Hotel Ever

Кооперативный отель от первого лица для Windows. Unity 6000.3.2f1 / C# / URP.

Текущая линия разработки: **1.3.0-grim-alpha1**. Оригинальные мрачные текстуры покрывают отель, персонажей, предметы, руки и планшет персонала. На постоянном HUD только смена/время и шкалы здоровья/выносливости. Все подробности, предупреждения и управление — в планшете на Tab. Обучение — редкие временные подсказки сверху, H скрывает текущую; локальное отключение не меняет учебный темп. Реальная выносливость ограничивает бег. Механики опасных смен, гости/запросы, шесть номеров, брони, многодневные проживания, экономика и сохранения остаются. Это alpha на пути к релизу: внешний Steam WAN и проверка удобства/интересности людьми ещё необходимы.

Откройте папку `Worst Hotel Ever` в указанной версии Unity. Запустите `Tools/Build-Windows.ps1` из PowerShell: тесты выполнятся перед Windows-сборкой в `Builds/Windows`. Для игры на другом ПК нужна вся эта папка, не только EXE. Сборки, Library и результаты отдельных запусков не хранятся в Git.

Для текущей текстурной версии: `Tools/Build-Windows.ps1 -Grim` → **`Builds/WindowsGrim`**, обычный Mono player без development watermark. Проверка: `Tools/Test-GrimCandidate.ps1` (или `-SkipBuild`), итог `TestResults/grim-candidate-results.txt`. Фиксируются hash runtime и всех сериализованных графических ассетов. Старые Windows/WindowsUI/WindowsTablet и выданные ZIP не перезаписываются. `PLAYTEST_DANGER.cmd` продолжает тот же отдельный тестовый отель: перед обычной игрой закройте старую версию, чтобы два хоста не писали один слот одновременно. Полная проверка сравнивает все три постоянных слота и backup; не запускайте её одновременно с человеческой игрой в этот слот.

Полная автоматическая локальная проверка: `Tools/Test-DangerCandidate.ps1` (или `-SkipBuild`, если текущая сборка уже готова). Включает прежние регрессии `Test-MvpCandidate.ps1` и новые проверки production-v3. Нужен доступный графический Windows-сеанс. Сценарии запускаются последовательно в отдельных тестовых слотах; итог — `TestResults/danger-candidate-results.txt`. Перед внешней приёмкой дополнительно просматриваются реальные снимки UI/мира. `PLAYTEST_DANGER.cmd` выбирает отдельный постоянный слот, не трогая основной отель и прошлый MVP-плейтест.

Прямой кооператив проверяется локально несколькими процессами. Steam AppID 480 — только экспериментальный режим; проверка через интернет на двух настоящих ПК/аккаунтах остаётся обязательной. Это не коммерческий Steam-релиз.
