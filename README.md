# Worst Hotel Ever

Кооперативный отель от первого лица для Windows. Unity 6000.3.2f1 / C# / URP.

Текущая линия разработки: **кандидат внутреннего MVP 1.0.0** — четыре стартовых номера и два приобретаемых, два сотрудника, четыре архетипа гостей, запросы и жалобы, бронирования и многодневные проживания, оборудование и общие коммуникации, экономика, улучшения, сохраняемый режиссёр событий и общий обзор отеля. Сохранения прежних версий поддерживаются. Внешняя проверка двумя людьми на разных ПК ещё необходима; кандидат не объявляется принятым MVP или коммерческим релизом.

Откройте папку `Worst Hotel Ever` в указанной версии Unity. Запустите `Tools/Build-Windows.ps1` из PowerShell: тесты выполнятся перед Windows-сборкой в `Builds/Windows`. Для игры на другом ПК нужна вся эта папка, не только EXE. Сборки, Library и результаты отдельных запусков не хранятся в Git.

Полная автоматическая локальная проверка: `Tools/Test-MvpCandidate.ps1` (или `-SkipBuild`, если текущая сборка уже готова). Нужен доступный графический Windows-сеанс. Сценарии запускаются последовательно в отдельных тестовых слотах; итог — `TestResults/mvp-candidate-results.txt`. Перед внешней приёмкой дополнительно просматриваются реальные снимки UI/мира.

Прямой кооператив проверяется локально несколькими процессами. Steam AppID 480 — только экспериментальный режим; проверка через интернет на двух настоящих ПК/аккаунтах остаётся обязательной. Это не коммерческий Steam-релиз.
