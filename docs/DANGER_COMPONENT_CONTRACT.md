## DTO semantics

Crew exactly slots0/1. Connection id0 maps0, every partner id maps1. `joined` tracks participation in current shift, not connection. PlayerState is ephemeral; crew life/health/position survive Load and disconnect. Life healthy (>0 HP), downed (0 HP, bleedout >0), dead (0 HP, no bleedout). There is no revive by disconnect or replacing connection ID. Players synchronize durable crew position on successful pose/leave, restore it on rejoin if already participated. In preparation/new day roster heals, clears downs/rescues, preserves joined for connected participants, positions reset safely. Empty server player-list alone does not cause wipe.

Danger.status briefing/active/won/failed; hotel phase stays preparation/open/closing/summary. In relief, finish uses normal shift semantics, no reward/win. `outcome` terminal textual code (completed/evacuated/wipe/collapse/incomplete/relief); reason is short RU. `settled` ensures rewards/penalties happen once. Counts wins/losses/streak/bestStreak persist across days. `serial` increments once per day, no repeat start reroll. Incident room IDs unique, maximum3, owned101..106. Planned forecasts are saved once; mode switch at preparation consumes no RNG. `requiredIncidents` selects first2 standard / first3 bold / 0 relief, remaining incident records may remain planned. Active/warning count cap1 standard,2 bold; grace25s after resolution. Health100, warning10s, downed45s, shield7s after rescue; medkits3, shared selfRescues1 per shift. No paid rescue-loop reward.

Default tuning (adjust with evidence, notify parent): standard2 incidents/2 service points/minimum180s/reward180/penalty80; bold3/4/260s/320/120; relief0/0/0/0/0. Service point from successful new guest assignment + first factual request fulfillment (already one-shot rewarded), not from repeat commands/compensation/relocation. Existing guests still provide request points. No cash quota. Individual damage zones only; ordinary puddles harmless. Ignored active unisolated incidents erode safety; safety0 starts visible30s final window; repair recovers safety35. Zone electric pulses, steam steady, fumes slower; never instant-kill or unavoidable mapwide HP loss. Contract cannot win while any participating crew dead/downed or unresolved required incident; successful early finish at desk requires service/minimum time. Host nextday from terminal danger summary bypasses proximity/life to avoid dead-host lock.

## Shared static rules API (simulation worker owns)

`HotelDangerRules.Enabled(state)`, `Crew(state, ulong)` returns slot, `Slot(ulong)`; `CanAct(state,id)` (old state true); `Incident(state,int)`; `Source(HotelIncidentState)` Vector3; `Control(int room)` Vector3; `Radius(HotelIncidentState)` float; `IsHot(HotelIncidentState)` bool; `IsWorkTarget(string)` bool; `TryTarget(state,string,out Vector3)` bool; `WorkError(state,ulong,string)` string (empty=allowed), `WorkSeconds(state,string)` float; `KindName(string)`, `ModeName(string)`, `Objective(state)` string; `PowerAvailable(state,room)` / `WaterAvailable(state,room)` incorporate base utility faults AND only the relevant isolated active incident. All queries read-only, no RNG/mutation.

Targets: `hazard_N` at Source for repair; `isolate_N` at Control for latched isolation; `rescue_0/1` at durable crew position; `recover_0/1` self-help (virtual focus of downed local player); `firstaid` at (-6.5,1.1,-3.3); `alarm` at (1.45,1.25,-6.4). Control = Door(room)+(sign*.6,1.05,-.4), inside doorway so existing SameAccessibleArea permits corridor approach. Sources: electric=RoomTarget(tv), steam=RoomTarget(sink), fumes=RoomTarget(trash), xz zones, radius<=1.8 (never crosses room shells). Read-only target validation must require canonical IDs and owned rooms. Every repair/rescue validates reachable short line via existing Walkable samples as well as distance.

Isolation: empty hand, 2s, warning/active only; stops damage + pressure, persists until repair. Electrical source -> toolbox6s; steam -> toolbox6s; fumes -> mop5s. Repair requires isolation. Revive colleague healthy rescuer, empty hands, 5s, one medkit; self recovery downed self, 6s, one medkit AND shared selfRescues; heal at firstaid 4s, consumes medkit and restores HP, cannot waste at full HP. Alarm 3s alive/empty, evacuates and fails without killing healthy crew. Down/dead drops held item, cancels every affected lease. Never allow rescue dead/healthy/self via teammate path.
