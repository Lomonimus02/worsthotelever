# Фактический прогресс pre-MVP

Начало: 22 сентября 2026. Основной план: ../WORST_HOTEL_EVER_MASTER_PLAN.md.

## Границы текущей сборки

Windows x64, первое лицо, 2 сотрудника, 4 номера, перенос предметов, гости/заселение/багаж/полотенца, уборка кровати и мусора, ремонт течи и отдельная уборка воды, деньги/итоги смены/улучшения, сохранение и продолжение. Стилизованные оригинальные процедурные модели. Steam-релиз не входит в pre-MVP.

## Среда

- Unity 6000.3.2f1 (6.3 LTS), установлен Windows Standalone Support.
- Уже созданный владельцем URP-проект: `Worst Hotel Ever/`; не переносим и не уничтожаем его исходные сцены.
- URP 17.3.0; Input System 1.17.0; NGO 2.7.0 (добавлен, проверка импорта впереди).
- GPU: NVIDIA GeForce RTX 2060 SUPER. Свободно на C: около 46 GiB при старте.

## Этапы выполнения

- [ ] A. Воспроизводимая сборка и каркас.
- [ ] B. Первый этаж отеля, первое лицо и предметы.
- [ ] C. Авторитетная сетевая сессия двух процессов.
- [ ] D. Гости, сервис, уборка, поломки, задачи.
- [ ] E. День, экономика, улучшения и сохранение.
- [ ] F. Автотесты, тест двух процессов, визуальная проверка, передача EXE.

## Ограничения проверки

Локальный сетевой тест не доказывает NAT traversal/Steam internet. Внешний тест с двумя аккаунтами и компьютерами фиксируется отдельно. Непроверенные пункты не отмечаются выполненными.
