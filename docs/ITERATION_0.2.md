# Итерация 0.2 — понятная первая смена и повторная проверка

Основание: просьба владельца самостоятельно проверить игру и продолжить разработку.
Базовый коммит: 8586d82, pre-MVP 0.1. Не считаем локальный кооператив подтверждением Steam WAN.

## План и критерии приёмки

1. Повторить 20 native-тестов исходной версии и двухпроцессный co-op smoke.
2. Независимо проверить сеть/сохранения в существующей задаче QA. Исправить подтверждённые ошибки с регрессиями.
3. Добавить сохраняемую контекстную помощь первой смены: реальные действия обоих сотрудников отмечают освоение; подсказка выбирается из состояния мира и предмета в руках. Нет учебных денег или повторного создания объектов.
4. Объяснить доступность заселения, состояние цели, владельца багажа, причину недовольства и последствия преждевременного завершения смены. Хост может отключить/включить помощь без сброса прогресса.
5. Добавить понятный ориентир к цели подсказки и закрытие списка задач повторным TAB. Это ориентир, не автоматическая прокладка пути сквозь стены.
6. Проверить старые сохранения, новые подсказки, реальную Input System/сеть, сборку Windows и интерфейс. Обновить README, статус, отдельный ZIP и журнал результатов.

## Параллельные зоны

- Текущая задача: интеграция, UI/первое лицо, сборщик, сетевые сценарии, исправления QA.
- «Игровая логика и сохранения»: HotelTypes, HotelSimulation, HotelOnboarding и его native-тесты; отдельный worktree.
- «Независимая проверка pre-MVP»: read-only QA сети/save/Steam, отдельный отчёт.

Не увеличиваем число игроков, не меняем цены/темп, не добавляем новый этаж. Стадия 08 мастер-плана остаётся частично выполненной: здесь контекстная помощь, а не полный режиссируемый tutorial с адаптивной нагрузкой.

## Результат

Пункты 1–6 реализованы; подробные доказательства и границы в `reports/release-0.2.md`. Дополнительно появился повторяемый `Tools/Test-UI.ps1`, а сборщик проверяет GUID метаданных до запуска Unity и ждёт сам Editor, не долгоживущую службу лицензирования.

Следующий отдельный этап: довести сценарий первых двух дней с адаптивной нагрузкой для новичка и вынести параметры гостей/запросов в определения данных. Внешний Steam-тест на двух ПК остаётся обязательной независимой проверкой, не подменяется новыми локальными сценариями.
