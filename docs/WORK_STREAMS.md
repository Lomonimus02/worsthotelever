# Задачи разработки

Все задачи создаются по прямому запросу владельца. Общий источник решений — MASTER_PLAN и COMPONENT_CONTRACT. Не смешиваем worktree и не запускаем несколько Unity Editor.

- Интеграция / Windows EXE / сеть / первое лицо / UI: текущая задача `01a0c4ca-8d11-7ea0-8736-62c94735d137`, C:/Normal/Programs/Game.
- Логика / сохранение / модульные сценарии: `01a0c600-c1ce-7432-a3b8-4bfb934136ff`, отдельный worktree, отчёт docs/reports/simulation.md.
- 3D-отель / геометрия / визуальные состояния: `01a0c600-c1ce-7432-a3b8-4bdbcdfd8416`, отдельный worktree, отчёт docs/reports/world.md.
- Steam lobby/relay и проверка совместимости: `01a0c60b-4431-7793-8a03-86c1e843f04a`, отдельный worktree, отчёт docs/reports/steam.md. Прямое подключение по IP остаётся запасным вариантом.
- Независимая проверка создаётся после первой интегрированной сборки — проверять пустой проект сейчас неэффективно.

Интеграция через проверку diff и cherry-pick конкретного коммита. Задачи не меняют файлы других компонентов без координации. Отчёты содержат ограничения и фактически выполненные проверки.
