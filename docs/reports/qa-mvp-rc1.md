# Независимая проверка интеграции MVP

22.09.2026. База: `7dcbb976187261c136c8e69a3977dcf89f3249f0`, плюс интегрированные коммиты MVP и рабочие изменения. Два отдельных read-only прохода: сеть/codec/границы сохранения и Game/input/lifecycle. Проверяющие читали чужие изменения и связанные вызовы по skill `code-review`; Unity и EXE они не запускали. Все исполнения ниже принадлежат интегратору.

## Три обнаруженных P1

- **M01 — коллизия ID после миграции.** Подготовка старого дня 2, все номера закрыты, спрос не выделил ID: `nextId=1`. Покупка второго ящика создавала ещё один `toolbox_1`, после чего строгая проверка блокировала save/снимки. Генератор теперь пропускает ID сохранённых предметов и MVP-записей/party. Новый native сценарий воспроизводит исходные условия, покупает второй ящик и выполняет настоящие Validate/Save/Load. PASS.
- **M02 — большой старый отель останавливался даже в одиночку.** Host Update пытался кодировать снимок до поиска получателей; превышение нового wire cap выставляло `NeedsRecovery`. Теперь без удалённых игроков кодирования нет. Вход проверяет возможность отправки; при последующем превышении отключаются только клиенты с понятной причиной, хозяин сохраняет живой мир и продолжает работу. Дополнительно полностью атомарная подготовка миграции проверяет и будущий forecast до замены корня. Слишком большой, но валидный v1 остаётся v1 без уничтожения вещей/журнала. Native тест на 1000 старых предметов и повторную миграцию после очистки прошёл. Отдельный Windows-сценарий проверяет production-resume и продолжение часов.
- **M03 — разные лимиты Unicode у отправителя и получателя.** Модель ограничивает UTF-16 JSON, но некоторые BMP-символы требуют три UTF-8 байта вместо двух. Прежний распаковщик отвергал пакет, который encoder принял. Распакованный поток теперь ограничен математическим максимумом `3 × число допустимых UTF-16 code units`; после строгого UTF-8 decode снова проверяется канонический UTF-16 бюджет. Лимит самого пакета не увеличен. Native тест с 180 записями по 512 CJK-символов выполняет Validate и точный roundtrip; отдельный oversized expansion/bomb отвергается. PASS.

## Дополнительные исправления при интеграции

Unity JsonUtility восстанавливал отсутствующий inline MVP-объект как экземпляр по умолчанию: v1 определяется явной версией и нормализуется на границах, а v2 требует отдельный маркер `mvp.schema=2`, который нельзя получить одним default-конструктором. Проверки missing payload, старого оригинального JSON и future-version защиты прошли. Переход проверяется на отдельном кандидате, не на половине живого отеля.

Отдельный preview PhysicsScene заменил runtime-only создание сцены в Edit Mode; все 11 world-сценариев теперь исполняются настоящим Unity. Исправлены две невалидные GUID мета-файлов и неоднозначный `CompressionLevel` в тесте. Настроены накопление мусора и износ коммуникаций: микрослед эксплуатации не создаёт немедленную жалобу, общие поломки действительно достигаются в десятидневном цикле. Тест дедупликации общей аварии обновлён под человеческие подписи вместо внутренних `utility_*` ID.
