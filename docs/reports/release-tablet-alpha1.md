# Windows-кандидат 1.2.0-tablet-alpha1

23 сентября 2026, упаковка после полного строгого прогона. Это alpha-итерация интерфейса, не коммерческий релиз и не подтверждённая интернет-приёмка.

## Получение и запуск

Локальная готовая игра: `Builds/WindowsTablet/PLAYTEST_DANGER.cmd`. Прежняя `Builds/WindowsUI` содержит старый бумажный журнал; для планшета используйте именно WindowsTablet. Launcher выбирает постоянный отдельный danger-слот. Перед игрой закройте прежний экземпляр: одновременно два хоста не должны сохранять один отель.

Для другого Windows-ПК передайте и полностью распакуйте `Builds/WorstHotelEver-1.2.0-tablet-alpha1-Windows.zip`, затем запустите находящийся внутри `PLAYTEST_DANGER.cmd`. Одного EXE недостаточно. Архив не загружался как публичный GitHub Release; исходники и документы хранятся в репозитории.

## Что изменилось

Постоянно видны только смена, время, здоровье и настоящая выносливость. Tab поднимает интерактивный стилизованный планшет; все меню/задачи/предметы/уведомления/предупреждения и настройки внутри. Учебные сообщения сверху кратковременны, H скрывает текущее; личное отключение доступно в Помощи. Планшет не останавливает мир.

Ограничения: GUI-корпус, не физический 3D-предмет; выносливость локальная, не сохраняется/не реплицируется и не является античитом. Человеческая оценка удобства и внешняя Steam-сессия двух ПК/аккаунтов ещё необходимы. Протокол `WHE-danger-5` и save/content v3 прежние; обоим игрокам нужна одинаковая сборка.
