# Worst Hotel Ever — Design Documentation

Этот архив содержит собранные design-документы по проекту **Worst Hotel Ever**.

## Основная идея

Кооперативная systemic hotel-management игра на 2–4 игроков, где команда физически управляет постепенно растущим отелем.

Ключевая петля:

**Run Hotel → Survive Chaos → Earn Money → Improve Hotel → Create More Chaos → Repeat**

Основные принципы:

- нет жёстких классов игроков;
- важные предметы физически существуют в мире;
- успех приводит к росту спроса и расширению;
- расширение создаёт новую нагрузку и логистические проблемы;
- провалы чаще создают последствия и новые задачи, а не Game Over;
- отель и его состояние сохраняются между днями;
- хаос должен возникать из пересечения систем, а не только из скриптов.

## Состав архива

Документы пронумерованы в рекомендованном порядке чтения.

> Примечание: ранние документы собраны по зафиксированным итогам наших design-сессий, а более поздние — по сформированным подробным версиям. Формулировки местами нормализованы, но принятые решения сохранены.
