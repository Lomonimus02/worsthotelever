# Worst Hotel Ever — Guest Interaction System

## Guest Lifecycle

Potential  
→ Reservation / Walk-in  
→ Arrival  
→ Waiting  
→ Check-in  
→ Assigned Room  
→ Stay  
→ Requests / Activities / Problems  
→ Check-out  
→ Payment  
→ Review / Reputation  
→ Leaves

## Reception

Guests физически приходят в Lobby и формируют очередь.

Queue имеет:

- order
- waiting time
- patience impact

Check-in простой и быстрый.

## Room Assignment

Room выбирается Player.

Это позволяет:

- mismatch
- intentional compromise
- strategic room use

## Reservations vs Walk-ins

Walk-in можно отказать.

Провал reservation обычно должен быть болезненнее, чем отказ walk-in.

## Baggage

Luggage физически существует.

Player может:

- carry
- deliver
- store
- put on Cart

## Guest Needs

Possible needs:

- Rest
- Cleanliness
- Service
- Food
- Comfort

MVP может использовать часть из них скрыто.

## Requirements

Guest can have:

- Mandatory Requirements
- Preferred Requirements

Room / Hotel may satisfy or violate them.

## Traits

MVP examples:

- Patient
- Impatient
- Messy
- Demanding
- Friendly

Later:

- Neat
- Quiet
- Party Lover
- Clumsy

## Archetypes

MVP:

- Tourist
- Business
- Family
- VIP

Guest = Archetype + Traits + Requirements + Preferences + Request Pool.

## Requests

MVP:

- Towels
- Coffee
- Room Cleaning
- Baggage Delivery

Requests can expire into complaints.

## Satisfaction

Internal numeric system may exist.

Player sees simpler qualitative feedback:

- Happy
- Fine
- Annoyed
- Angry

## Memory

Guest should remember meaningful moments:

- long wait
- dirty room
- fast recovery
- broken equipment
- compensation
- successful request

Reviews use these memories.

## Early Departure

Later or rare MVP behavior:

severely unhappy Guest may leave early.

## Core Principle

Guest должен восприниматься как физический посетитель Hotel, а не как карточка с задачами.
