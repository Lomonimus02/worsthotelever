# Worst Hotel Ever — Guest Problems & Complaints

## Core Separation

**Problem** = objective world state.  
**Complaint** = Guest reaction to that problem.

## Lifecycle

Problem  
→ Guest detects  
→ reacts  
→ Complaint  
→ team becomes aware  
→ response  
→ resolved / compensated / ignored  
→ Guest evaluates response  
→ satisfaction changes  
→ complaint closes or escalates

## Problem Sources

- Room
- Service
- Environment
- Reservation
- Property
- Social

## Detection

Guest does not complain about everything globally.

They must usually:

- encounter
- observe
- suffer
- wait

Tolerance differs by Trait / Archetype.

## Player Responses

- Fix
- Replace / Deliver
- Move Guest
- Compensate
- Ignore

## Important Rule

Compensation does **not** remove the physical Problem.

It only affects Guest reaction.

## Escalation

Simple MVP escalation:

Complaint  
→ Angry  
→ Critical

Higher stages can produce:

- demand compensation
- demand room move
- refund
- early departure

## Room Move

Requires:

- suitable free room
- reassignment
- baggage logistics

## Repeated Problems

Multiple failures during one stay should compound.

## Shared Root Cause

If one root problem affects several Guests, system should avoid producing meaningless task spam.

## Reviews

Review considers:

- number of complaints
- severity
- response speed
- recovery
- compensation
- room quality
- wait time

Good recovery may partially or strongly repair final impression.

## MVP Complaint Types

- Dirty Room
- Broken TV
- Broken Toilet
- Missing Towels
- Long Check-in
- Baggage Problem
- Noise

## Core Principle

Complaint должен быть понятной реакцией на происходящее в Hotel, а не случайным debuff.
