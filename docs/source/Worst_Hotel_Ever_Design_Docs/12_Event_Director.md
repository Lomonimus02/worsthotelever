# Worst Hotel Ever — Event Director

## Purpose

Controls when unexpected events are introduced.

Does not own all normal gameplay.

## Event vs Normal Consequence

Normal:

Worn Sink breaks.

Event:

Storm / Guest Rush / special arrival changes context.

## Categories

- Minor
- Operational
- Guest
- Major
- Planned

## Director Inputs

- Hotel state
- Workload
- Recent events
- Reputation
- Guest mix
- Amenities
- Hotel history
- time of day
- event cooldowns

## Weighted Randomness

Use controlled weighted selection.

The Director may choose:

**nothing.**

## Difficulty Budget

Events have cost.

Prevent unfair overlap.

## Cooldowns

- Global cooldown
- Category cooldown
- Event-specific cooldown

## Anti-Repeat

Track recent events.

## Duration

- Instant
- Temporary
- Until Resolved
- Scheduled

## Planned Events

Later large events can be:

- previewed
- accepted / refused
- prepared for

## Outcome

Should use normal systems.

No separate mission rules where possible.

## Scope

Events may target:

- Guest
- Room
- Floor
- Amenity
- Whole Hotel

## Positive / Neutral Events

Not everything should be punishment.

## MVP Pool

- Guest Rush
- Unexpected Walk-in Group
- VIP Arrival
- Elevator Failure
- Minor Water Problem

Rules:

- max one major/high-cost event
- workload protection
- cooldown
- anti-repeat

## Core Principle

Director should create interesting context, not fake difficulty or punish success directly.
