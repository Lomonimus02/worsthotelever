# Worst Hotel Ever — Large Events

## Definition

Large Event temporarily restructures normal Hotel gameplay.

It is not a separate minigame.

## Event Structure

Template fields:

- Type
- Start
- Duration
- Guest Count
- Group
- Room Requirements
- Amenity Requirements
- Special Needs
- Revenue
- Reputation impact
- Noise
- Cleaning
- Risk
- Outcome

## Guest Integration

Event Guests are normal Guest entities.

They have:

- Group ID
- reservations
- rooms
- requests
- complaints
- luggage

## Group Reservations

Can block multiple Rooms.

## Requirements

- Mandatory
- Preferred

## Preparation

Event can create preparation tasks.

But Event still starts if Hotel is imperfectly prepared.

No hard mission checklist.

## Phases

- Preparation
- Arrival
- Main
- Departure
- Cleanup

## Pressure

Synchronized arrivals and departures create natural peaks.

## Outcome

Non-binary.

Based on:

- Guest satisfaction
- complaints
- service
- preparation
- unresolved problems

## Examples

- Tourist Bus
- Conference
- Wedding
- VIP Delegation
- Inspector
- Emergency Group

## MVP / Early

- Tourist Group / Bus
- maybe VIP visit

## Alpha

- Conference
- Inspector

## Later

- Wedding
- advanced event types

## Core Principle

Large Events should stress existing systems in new combinations rather than introduce unrelated rules.
