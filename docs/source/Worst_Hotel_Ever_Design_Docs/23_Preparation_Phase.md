# Worst Hotel Ever — Preparation Phase / Between Days

## Purpose

Preparation is calm strategic time while the physical Hotel remains real.

## Flow

Day Summary  
→ Reviews / Reputation  
→ Forecast  
→ Preparation  
→ Open Hotel

## Pressure

During Preparation:

- no new Walk-ins
- no random routine requests
- no normal Director Events

World state persists.

## Summary

Explain:

- revenue
- costs
- reviews
- major reasons

## Forecast

Show tomorrow:

- reservations
- expected arrivals
- check-outs
- likely occupancy
- planned Event
- important requirements

Do not reveal every surprise.

## Room Readiness

Players can inspect:

- Ready
- Dirty
- Broken
- OOS
- Occupied overnight

## Physical Preparation

Players can:

- clean
- repair
- move tools
- position Carts
- organize supplies

No global “Clean All”.

## Upgrades

Purchased here.

Appear physically in Hotel.

## Expansion

Preview:

- cost
- capacity
- workload
- new systems

## Pricing

Set next-day price.

## Closing Areas

Later:

- Rooms
- Wings
- Amenities

to manage workload.

## Supplies

MVP:

automatic restock with aggregated cost.

## Planned Events

Later accepted here.

## No Infinite Exploit

Occupied Guests are effectively inactive / sleeping during Preparation.

Cannot farm services endlessly.

## Start Ritual

Players choose:

**Open Hotel**

when ready.

Warnings may appear but avoid unnecessary hard blocks.

## MVP

- Summary
- Tomorrow Reservations
- Room states
- persistent Repairs
- auto-restock
- 3–5 upgrades
- price
- room expansion
- start next day

## Core Principle

Preparation should convert yesterday’s chaos into tomorrow’s decisions.
