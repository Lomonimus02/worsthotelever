# Worst Hotel Ever — MVP Scope Consolidation

## MVP Purpose

Prove that a small physical co-op Hotel creates fun, repeatable, systemic chaos.

## Core Loop

Guest arrives  
→ Check-in  
→ Room assignment  
→ Baggage / Service  
→ Room use  
→ Dirt / Breakdown  
→ Request / Complaint  
→ Players prioritize  
→ Check-out  
→ Turnover  
→ Money / Review / Reputation  
→ Upgrade  
→ Next Day differs

## MVP Success Criteria

Players should:

- naturally split work
- communicate priorities
- care about physical logistics
- feel Rooms persist
- understand causes of Guest problems
- experience natural cascades
- feel expansion makes Hotel harder naturally
- want one more Day

## North Star

Choose features that strengthen:

**physical co-op Hotel chaos**

not management depth for its own sake.
