# Worst Hotel Ever — Visual Design & Art Direction

## Reference Direction

Reference target:

- stylized 3D
- cartoon-like proportions
- clean readable environments
- exaggerated characters
- bright colors
- comedic tone
- simple but expressive materials
- strong multiplayer readability

Reference is directional, not for copying specific assets or scenes.

## Core Style

**Stylized, friendly, readable 3D co-op chaos game.**

Avoid:

- photorealism
- gritty simulation look
- hyper-detailed interiors
- flat prototype low-poly look as final target

## Main Goals

1. Readability
2. Comedy
3. Production practicality
4. Scalability

## Characters

- slightly caricatured
- larger head
- readable silhouette
- expressive simple face
- not full chibi
- not realistic anatomy

## Player vs Guest Readability

Use:

- staff uniforms
- color accents
- badges
- accessories

## Guest Visual Categories

Business:
- cleaner / formal silhouette

Tourist:
- casual / brighter

Family:
- group composition

VIP:
- more polished / distinct

## Animation Tone

- expressive
- slightly exaggerated
- lively
- a little awkward / comedic

## Hotel Environment

- simplified geometry
- clear spaces
- exaggerated scale where useful
- readable landmarks

## Detail Density

Do not overload Rooms with tiny decor.

Gameplay already contains:

- Guests
- luggage
- tools
- dirt
- Problems
- water
- furniture

## Materials

- clean
- stylized
- moderate detail
- readable plastic / wood / metal / fabric / ceramic

## Color

Baseline:

- warm
- welcoming
- lively

Chaos states:

- stronger contrast
- wet reflections
- warning accents
- flicker
- visual mess

## Lighting

Bright and gameplay-readable.

Morning:
- fresh

Afternoon:
- neutral

Evening:
- warmer

Night:
- darker ambience but still easy to play

## Camera

Likely:

- third-person
- slightly elevated
- enough FOV for nearby chaos

## Scale

Rooms slightly larger than realism.

Objects slightly chunkier:

- Suitcase
- Toolbox
- Towels
- Cart
- Mop

## Cleaning Visual Language

- messy Bed
- dirty Towels
- visible Trash
- overflowing Bin
- obvious Wet Floor

## Breakdown Visual Language

- TV dead / flickering
- Sink visibly leaking
- broken Toilet clear
- Lamp flicker
- Elevator warning state

## Furniture Tiers

Should look progressively better without reading stats.

## Hotel Visual Progression

Start:

- cheap
- simple
- slightly tired
- motel energy

Later:

- warmer
- cleaner
- richer
- more personalized
- better furniture

Chaos becomes funnier against a nicer Hotel.

## VFX

Stylized:

- Water splashes
- Sparks
- Steam
- Dust
- Repair FX
- Complaint / emotion cues

## UI

- clean
- rounded / friendly where appropriate
- playful but functional
- never spreadsheet-first

## MVP Visual Scope

Characters:
- simple staff
- small Guest set

Environment:
- Lobby
- 1–2 Room shell variations
- hallway
- Storage
- Utility

Props:
- luggage
- towels
- coffee
- tools
- cleaning props

Effects:
- Leak
- Puddle
- Flicker
- Repair

## Production Rule

Early quality can be lower, but must preserve:

- coherent style
- silhouettes
- readability
- comedic clarity
- correct scale

## Core Principle

**Stylized Characters + Readable Props + Bright Hotel Spaces + Clear Problem States + Light Comedy**
